# 🏗️ BuildMetric

**Free, Engineer-Reviewed Construction Calculators & Technical Guides for the USA, UK & Australia.**

BuildMetric is an independent publisher of construction calculators and technical reference guides. Built for building professionals, contractors, quantity surveyors, and engineers.

## 🌟 Features

- **Engineer-Reviewed:** Every formula and guide is reviewed by practising professionals.
- **3 Markets:** Code-aware content tailored for US (IRC), UK (BS 5534), and AU (AS 1684) standards.
- **Free Forever:** No paywalls, no sign-ups, no gated results.
- **SEO Optimized:** Rich JSON-LD schema, Open Graph tags, and international `hreflang` targeting.
- **Monetization Ready:** Cleanly placed AdSense placeholders and affiliate disclosure structures.
- **Responsive UI:** Premium, modern design built with Tailwind CSS, optimized for mobile.

## 🛠️ Tech Stack

- **HTML5** (Semantic structure)
- **Tailwind CSS** (via CDN for rapid styling)
- **Vanilla JavaScript** (For UI interactions, mobile menu, and smooth scrolling)
- **GitHub Pages** (Hosting)
